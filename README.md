# HACHE_annexes_memoire_M2

Bienvenue dans les annexes de mon mémoire de Master 2 intitulé _Au coeur d'une bibliothèque théâtrale : une base de données à partir des factures de la collection Auguste Rondel_ . 

Ce dépôt a pour but de visualiser certaines annexes qui ne peuvent pas être directement contenues dans mon mémoire. 

Il contient : 
- La documentation produite pendant mon stage sur les usages ultérieurs de la base de données, renseignée dans l'annexe C du mémoire (p. 91-92) (fichiers _HACHE_Raphael_Recommandations_usages_base-2.pdf_ et _transcription automatique des factures - tests, prompts et recommandations.pdf_)
- Deux fichiers .csv issus de transcriptions automatiques de factures de libraires réalisées avec plusieurs modèles d'IA (Ces fichiers sont inclus dans l'annexe E du mémoire, p. 105-115).

- ERRATUM : Ce dépôt contient aussi deux fichiers .pdf permettant une visualisation nette des annexes A.I. et A.II. du mémoire (il s'agit des fichiers _HACHE_annexe_A_I_ et _HACHE_annexe_A_II_). Les liens prévus à cet effet à l'origine, situés p. 87 du mémoire, ne sont pas cliquables. La présence de ces deux fichiers dans ce dépôt vise donc à corriger cette erreur.
